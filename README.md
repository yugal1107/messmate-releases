# MessMate Releases

Official Android builds of the MessMate app.

## Download

Get the latest APK from the [Releases page](https://github.com/yugal1107/messmate-releases/releases/latest).

## Install

1. Download the `messmate-<version>.apk` file on your Android phone.
2. Open it and allow "Install from unknown sources" if prompted.
3. To update, install the newer APK over the existing app.

iPhone users: use the web version (coming soon).

---

`theme-config/active.json` is the festival theme the app loads at runtime.
